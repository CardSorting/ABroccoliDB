# Contributing to BroccoliDB

The technical workflow, source map, and review checklist are in
[docs/CONTRIBUTING.md](docs/CONTRIBUTING.md). The repository uses the
Developer Certificate of Origin 1.1 (`DCO`) to establish contribution
provenance.

Every commit submitted for inclusion must include a sign-off line:

```text
Signed-off-by: Your Name <you@example.com>
```

Use `git commit -s` to add it. The sign-off certifies that you have the right
to submit the change under the project’s Apache-2.0 license; it is not a
copyright assignment and does not grant rights to submit confidential or
third-party material.

The pull-request workflow checks the complete proposed commit range for a
`Signed-off-by` line. A passing local build does not bypass that provenance
gate.

Before contributing, read:

- [DCO](DCO)
- [Apache License](LICENSE)
- [NOTICE](NOTICE)
- [Defensive Patent and IP Policy](PATENT-NON-AGGRESSION-PLEDGE.md)
- [Technical contribution guide](docs/CONTRIBUTING.md)
- [Security policy](SECURITY.md)

Do not submit confidential code, customer data, unreviewed generated output,
or material whose license is incompatible with Apache-2.0. Mark a message
`Not a Contribution` when it is only discussion and is not intended for
inclusion in the Work.
